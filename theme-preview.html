Key difference

  • MAI is creamier, darker, and more conventional.
  • Su is softer, more semantic, and uses traditional Chinese color roles.
  • Su reserves cinnabar red for errors and keeps frequent CLI text in ink/cool colors.

How to view

  • Open this file directly in a browser: open theme-preview.html
  • Use a browser with BlexMono Nerd Font Mono installed for the closest preview.
