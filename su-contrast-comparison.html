素 / Su Theme Contrast Comparison

对比 Su 原始调色板与当前 WCAG AA 调整版：保持宣纸、水墨、传统色的气质，同时让正文、 注释、语法色在常见背景上达到可访问对比度。

4.5:1+ 当前正文/语法色在 bg、bg_soft、bg_code、bg_hl 上全部满足 WCAG AA 正文标准。
3:1+ 大字号文本阈值自然满足，因为所有测试组合都已超过 4.5:1。
8 色 仍保留青花、天青、竹青、缃色、赭石、朱砂、黛紫、胭脂的语义体系。
0 关键语法色没有 RGB 距离小于 45 的近距离混淆色对。

Before: original Su

更轻、更柔，但部分注释与暖色语法在浅背景上低于 4.5:1。

// comments could fade too much in code blocks
type Theme = {
  name: string;
  contrast: number;
};

function checkContrast(theme: Theme) {
  const ratio = Math.max(theme.contrast, 4.5);
  return ratio < 4.5 ? "fail" : "pass";
}
